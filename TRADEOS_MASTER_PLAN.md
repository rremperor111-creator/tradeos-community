# TradeOS Community

## Mission

TradeOS Community is a completely free, open-source trading journal and analytics platform designed to be a true alternative to TradeZella.

The platform will prioritize:

* Free forever
* Open source
* Privacy first
* Self-hostable
* Local-first architecture
* MT5 support
* Community-driven development

This is not a SaaS product.

This is a free tool built for traders.

---

# Core Philosophy

Users own 100% of their data.

The platform should work:

* Offline
* Self-hosted
* On local machines
* With optional cloud backup

No feature should require a subscription.

No feature should be locked behind a paywall.
