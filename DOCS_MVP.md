# TradeOS Community MVP

## Phase 1 Goals

Build a functional open-source trading journal.

### Features

- Trade CRUD
- Trade Notes
- Screenshot Uploads
- Analytics Dashboard
- Strategy Tracking
- Psychology Journal
- Calendar View
- Equity Curve
- Data Export

## Out of Scope

- MT5 Live Sync
- Broker Integrations
- AI Assistant
- Trade Replay

These will be implemented in later versions.

## Success Criteria

User can:

- Add trades
- Edit trades
- Delete trades
- View analytics
- Track strategies
- Review performance

## Target

Release MVP as open source.
